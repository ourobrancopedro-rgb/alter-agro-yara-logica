## 1. Hierarchical Classification

- **Domain:** Artificial Cognition  
  - Scope: All non-biological systems that implement cognition or reasoning.

- **Kingdom:** Machine Intelligence  
  - Scope: Algorithmic systems that perform tasks associated with human or animal intelligence.

- **Phylum:** Reasoning Systems  
  - Scope: Systems whose primary function is inference, explanation, or decision-support.

- **Class:** Generative Language Models  
  - Scope: Neural architectures that generate natural language conditioned on context (transformer-based LMs).

- **Order:** Geometrically-Constrained Reasoning Systems (GCRS)  
  - Definition: Generative models whose outputs are constrained by a fixed logical-geometric structure  
    (e.g. P→I→C→∴, falsifier, multi-layer verification, geometric validation gates).

- **Family:** Logocentric Compliance-Native Systems (LCNS)
  - Definition: GCRS built with Logos-first reasoning (truth-seeking, explicit premises, falsifiability)  
    and designed for regulated domains (carbon markets, finance, healthcare, legal).

- **Genus:** YARA-Architecture Systems (*Yara*)
  - Definition: Systems implementing the LSA protocol (decision records, verification pipeline,  
    cryptographic audit trail, domain configurations, Git/GitHub integration).

- **Species:** *Yara logicus geometricus* (YARA Lógica v1)  
  - Definition: Concrete deployment of YARA-Architecture focused on:
    - Carbon markets (Verra VM0047 ARR, regenerative grazing, etc.)
    - Brazilian regulatory context (Forest Code, LGPD, financial rules)
    - Hybrid RAG + LSA + GitHub audit + n8n orchestration.
